# SD-Lab-Week01-Git-Practices

Laboratorio Semana 1 - Buenas prácticas en el uso de Git.

## Descripción

Proyecto de prueba para demostrar la aplicación de buenas prácticas de Git (ramas, commits descriptivos, merging, rebasing, stash, tags, etc.) utilizando GitLab como repositorio principal y GitHub como espejo.

## Tecnologías

- HTML5
- CSS3
- JavaScript (ES6+)
- Jest (pruebas unitarias)

## Estructura del proyecto

```
.

```
